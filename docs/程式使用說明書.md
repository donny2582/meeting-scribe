# MeetingScribe 程式使用說明書

MeetingScribe（會議紀錄產生器）把會議錄音轉成**逐字稿**，再由 AI 整理成**會議紀錄 .docx**（公文格式）與**心智圖**，
紀錄人員校對後即可陳核。

---

## 1. 安裝

1. 到 [GitHub Releases](https://github.com/donny2582/meeting-scribe/releases) 下載最新版的 `MeetingScribe_Setup_{版本}.exe`。
2. 雙擊安裝。**不需要安裝 Python**，預設只裝給目前使用者，**不需要系統管理員權限**。
   - 若出現「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」（安裝檔沒有數位簽章）。
   - 可勾選「建立桌面捷徑」。
3. 安裝完成後，從開始功能表或桌面的「**MeetingScribe 會議紀錄**」開啟。

**系統需求**：Windows 10／11（64 位元）、可以連上網際網路（雲端轉錄與 AI 整理）。

**解除安裝**：Windows「設定 → 應用程式」找到「MeetingScribe 會議紀錄」→ 解除安裝。設定、金鑰與會議資料會保留。

---

## 2. 第一次使用：設定金鑰

開啟後切到「**API 金鑰**」分頁：

1. **1. 語音轉錄**：選服務（Azure／OpenAI／Soniox），貼上金鑰（Azure 另選區域）→「儲存」→「測試連線」。
2. **2. 文字整理處理**：選 Anthropic Claude 或 OpenAI，貼上金鑰 →「儲存」→「測試連線」。
3. **3. 費用**（建議）：設定每月費用上限（美元，0＝不限制）。

金鑰怎麼申請請看 [API 金鑰申請說明](API金鑰申請說明.md)。燈號：綠色＝已設定、紅色＝需要但未設定、橘色＝建議設定。

---

## 3. 主要流程

```
錄音檔 ──「轉錄」分頁──▶ 逐字稿 ──「產出文件」分頁──▶ 會議紀錄 .docx、逐字稿 .docx、心智圖 PNG／XMind
                         ▲
已有的逐字稿檔（txt、srt、docx）── 匯入 ─┘
```

### 3.1「轉錄」分頁：錄音 → 逐字稿

1. **錄音檔**：選擇或拖放錄音檔，支援 mp3、m4a、aac、wav、wma、flac、ogg、opus、amr、aiff 等常見格式，以及 mp4、mov、mkv、avi、wmv 等影片（只取聲音）。清單以外的格式也會嘗試讀取，只要檔案裡有聲音就能轉錄；沒有聲音或已損毀的檔案會在送出前擋下，不會花費用。
2. **語音範圍**（選填）：只轉錄其中一段。
   - 拖曳拉桿兩端的藍色把手，或直接輸入起點／終點時間。
   - 用播放器試聽確認（跳到起點、播放／暫停、停止、跳到終點前 5 秒），播到終點自動停止。
   - 少數格式無法試聽時，仍可拖曳把手或輸入時間設定範圍並轉錄（畫面會說明）。
   - 逐字稿的時間碼對應**原始錄音**的時間（不是從 0 開始）。
3. **辨識設定**：引擎、會議語言（預設中文＋英文，可加日文、韓文）、講者人數、詞庫。
4. **輸出**：輸出資料夾（預設 `文件\MeetingScribe\輸出`）。
5. 按「**開始轉錄**」。下方會顯示進度、經過時間與執行紀錄，可以取消。
6. 完成後自動切到「**產出文件**」分頁。

引擎、語言與輸出資料夾會記住上次的選擇。

### 3.2「產出文件」分頁：修正 → 產出

**逐字稿來源**（三選一）：

| 來源 | 說明 |
|---|---|
| 轉錄結果 | 轉錄完成後自動帶入 |
| 匯入逐字稿檔案… | 已經有的 txt、srt、docx、json |
| 開啟已存的文件… | 之前按過「儲存修改」的文件 |

匯入 txt 有容錯：時間碼可以在行首或行尾、有沒有括號都可以；講者可以和內容同一行，也可以單獨一行
（例如會議軟體匯出的「00:04:07 演講者 1」，下一行才是內容）。「演講者 1」「Speaker 1」會統一成「講者1」。

**1. 逐字稿內容**
- 直接在表格中修正文字、修改單一片段的講者。
- **講者命名**：把「講者1」改成實際單位或姓名（例如「公路局」），全部片段一起改。
- **合併講者**：同一個人被分成兩個講者時合併。

**2. 會議資訊**（會議紀錄的表頭）
- 會議名稱（可以兩行，例如「○○計畫（草案）」換行「第2次研商會議紀錄」）
- 日期（顯示民國年與星期）、開始時間、散會時間（預設＝開始＋錄音長度，四捨五入到 5 分鐘）
- 地點、主席（記住最近 10 筆）、紀錄、參加人員、議程

**3. 產出項目**（至少選一項）
- **會議類型**：主題式（工作進度會議）、問答式（專家座談）、議程逐項式（研商會、審查會）。
- 逐字稿、討論事項、結論、待辦事項表、心智圖。

**4. 產出前的文字處理**
- **刪除贅字**（呃、嗯、那個、對對對、重複的字…）：先用規則刪除，有金鑰時再由 AI 處理。
  AI 結果必須通過「只刪不改」的驗證，否則改用規則結果。只影響產出的 Word 檔，畫面上的原文不變。

按「**產出文件**」開始。完成後可用「開啟會議紀錄」「開啟逐字稿」「開啟心智圖」「開啟這場會議的資料夾」查看。
修改內容記得按「**儲存修改**」，下次可用「開啟已存的文件…」繼續。

### 3.3 產出的檔案

每場會議一個資料夾：`輸出資料夾\{民國年月日}_{會議名稱}\`（例：`1151110_道安研商會議`），只放成品：

| 檔案 | 內容 |
|---|---|
| 會議紀錄_….docx | 公文格式（標楷體；壹、貳、參…；一、(一)、1.、(1)）。每條結論有 **Word 註解**標出依據的錄音時間與講者；AI 無法確定的內容以**黃色標示「（待查證）」**；可附待辦事項追蹤表 |
| 逐字稿_….docx | 講者對照表、依時間排列的發言內容 |
| 心智圖_….png | 由左往右展開的樹狀圖（寬度至少 2400 px，可放進簡報） |
| 心智圖_….xmind | 可用 XMind 開啟、繼續編輯 |

**AI 整理的內容一定要人工校對**後再陳核：檢查 Word 註解中的依據時間、處理黃色「待查證」的段落，校對完可刪除註解。

## 4. 其他分頁

| 分頁 | 用途 |
|---|---|
| **引擎評估** | 用自己的錄音比較各語音引擎。選測試錄音、勾選引擎後直接按「開始評估」即可做**快速比較**（處理時間、費用、講者數、詞庫詞彙出現次數、引擎之間的差異，並產生逐段對照表 `engines_side_by_side.csv` 讓您用 Excel 並排比對）。要計算字元錯誤率等正確率時，再按「產生標準答案草稿」→ 用 Excel 校正後存檔 → 勾選「沿用先前的轉錄結果」重新評估（不重複計費） |
| **詞庫** | 機關名稱、專有名詞、人名（例如「道安會報」「公路局」）。轉錄時提供給引擎提高辨識率。可用 Excel 開啟、新增、匯入、刪除；預設詞庫（道安業務）🔒 不可刪除；刪除的自訂詞庫會移到資源回收筒 |
| **API 金鑰** | 金鑰、各工作使用的模型、每月費用上限與本月已使用金額 |

**模型選擇**：模型名稱都是下拉選單；右邊「＋」可新增清單沒有的模型；「↻ 從服務更新模型清單」會用官方 API 取得目前可用的模型。

## 5. 費用

| 項目 | 估計 |
|---|---|
| 語音轉錄（Soniox） | 約 US$0.10／音訊小時 |
| 臺灣在地化（Opus 5.5，Soniox 才需要） | 每場約 US$1.00（改用 Sonnet 5.5 約 US$0.50） |
| 刪除贅字（Haiku 5.5） | 每場約 US$0.03 |
| 整理討論事項、結論、待辦（Sonnet 5.5） | 每場約 US$0.30 |

- 每次呼叫都記錄在 `%LOCALAPPDATA%\MeetingScribe\usage.csv`（可用 Excel 開啟，不含逐字稿內容）。
- 「API 金鑰」分頁 → 3. 費用：顯示本月已使用金額；用到 80% 變橘色，達到上限時停止新的工作。
- 金額是本程式依單價估算，實際以各服務的帳單為準。

## 6. 中斷了怎麼辦（餘額不足、網路中斷、按了取消）

**已經付費完成的部分一完成就存檔，不會遺失，也不必從頭開始**：

| 情況 | 怎麼繼續 |
|---|---|
| 轉錄中途中斷（分段轉錄、AI 在地化） | 對同一個錄音檔、同樣設定再按「開始轉錄」，從中斷處繼續，已完成的部分不重複計費 |
| Soniox 已送出，等結果時中斷 | 再按「開始轉錄」，伺服器已完成就直接取回，不重新上傳 |
| 產出文件時刪除贅字或 AI 整理中斷 | 再按「產出文件」，已完成的批次直接沿用 |

暫存放在 `%LOCALAPPDATA%\MeetingScribe\cache\`，超過 30 天沒用會自動刪除。

## 7. 檔案放在哪裡

| 位置 | 內容 |
|---|---|
| `文件\MeetingScribe\輸出\` | 產出的會議紀錄、逐字稿、心智圖（可在「轉錄」分頁更改） |
| `%LOCALAPPDATA%\MeetingScribe\jobs\` | 程式工作檔（document.json、轉錄原始結果、AI 整理結果） |
| `%LOCALAPPDATA%\MeetingScribe\cache\` | 中斷續跑用的暫存 |
| `%LOCALAPPDATA%\MeetingScribe\logs\` | 日誌（不含逐字稿內容；每個檔案最多 1 MB、保留 5 個舊檔），底部工具列「開啟日誌」 |
| `文件\MeetingScribe\問題回報\` | 按「回報問題」產生的回報檔（zip） |
| `%APPDATA%\MeetingScribe\config.toml` | 程式設定（底部工具列「開啟設定檔（進階）」） |
| `%APPDATA%\MeetingScribe\glossary\` | 詞庫 |
| Windows 認證管理員 | API 金鑰 |

右上角「**儲存程式設定**」（Ctrl+S）儲存金鑰、服務與模型、費用上限、轉錄偏好；逐字稿與會議資訊用「產出文件」分頁的「儲存修改」。

## 8. 程式出錯時

- **已知的狀況**（金鑰無效、餘額不足、網路中斷、檔案格式不支援…）：畫面會用中文說明原因與處理方式；已完成（已付費）的部分都有存檔，處理後再執行會從中斷處繼續。
- **程式本身的問題（bug）**：會跳出「程式發生錯誤」視窗，程式可以繼續使用，錯誤細節自動記錄在日誌。視窗上有：
  - **回報問題**：產生回報檔（zip），請寄給開發者並說明當時正在做什麼。
  - **開啟日誌**、**複製錯誤資訊**。
- **隨時回報**：底部工具列的「**回報問題**」也可以產生回報檔。回報檔只有程式版本、系統資訊、日誌與設定（已移除最近使用的地點、主席、紀錄人員姓名），**不含錄音、逐字稿與 API 金鑰，也不會自動上傳**。
- **設定檔格式錯誤**（例如用「開啟設定檔（進階）」修改時，路徑寫成 `"D:\會議"`）：開啟程式時會說明是第幾行出錯，可選「開啟設定檔修正」或「備份後用出廠設定啟動」（原檔改名保存、金鑰不受影響）。路徑請寫成 `"D:/會議"` 或 `"D:\\會議"`。
- 視窗標題會顯示版本號（例如 0.5.3），回報時請一併告知。

## 9. 常見問題

**Q：找不到 ffmpeg？**
安裝版已內附 ffmpeg，不需另外安裝。開發版請執行 `winget install Gyan.FFmpeg`。

**Q：金鑰測試失敗？**
確認金鑰完整複製（沒有多餘空白）、該服務帳戶已儲值；Azure 要確認區域與建立資源時選的相同。

**Q：講者都是「講者1、講者2」？**
語音引擎只能分辨不同的聲音，無法知道是誰。請在「產出文件」分頁用「講者命名」改成單位或姓名，AI 整理時會使用新名稱。

**Q：專有名詞一直辨識錯？**
到「詞庫」分頁加入正確寫法，下次轉錄時會提供給引擎。

**Q：怎麼確認安裝是否正常？**
在安裝資料夾（`%LOCALAPPDATA%\Programs\MeetingScribe`）開啟 PowerShell，執行：

```powershell
.\MeetingScribe.exe selftest --out "$env:USERPROFILE\Desktop\自我檢查"
```

不需要金鑰、不花費用，結果寫在桌面「自我檢查」資料夾的 `selftest_report.txt`。
