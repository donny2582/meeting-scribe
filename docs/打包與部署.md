# 打包與部署

把 MeetingScribe 打包成 Windows 安裝檔，讓使用者**不需要安裝 Python** 就能安裝使用（SPEC 第 12 章第 5 階段）。

```
原始碼 ──PyInstaller──▶ dist\MeetingScribe\（程式本體，約 411 MB）
                                │
                           Inno Setup 壓縮
                                ▼
                dist\installer\MeetingScribe_Setup_{版本}.exe（約 122 MB）──▶ GitHub Releases
```

---

## 1. 準備開發環境（只需一次）

| 工具 | 安裝方式 | 用途 |
|---|---|---|
| Python 3.12（或 3.11） | `py install 3.12` 或 python.org | 執行與打包 |
| 專案虛擬環境 | `.\scripts\setup.ps1` | 安裝 requirements-dev.txt（含 PyInstaller） |
| ffmpeg | `winget install Gyan.FFmpeg` | 隨安裝檔附上 |
| Inno Setup 6 | `winget install JRSoftware.InnoSetup` | 產生安裝檔 |

指令碼相容 Windows PowerShell 5.1 與 PowerShell 7。

---

## 2. 打包

```powershell
.\scripts\build.ps1
```

| 步驟 | 內容 |
|---|---|
| 1/5 準備 ffmpeg.exe | 依序找 `assets\ffmpeg\ffmpeg.exe`、PATH、winget 安裝位置，複製到 `assets\ffmpeg\`（不納入 git） |
| 2/5 產生程式圖示 | 由 `assets\icon.png` 產生多尺寸 `build\meeting_scribe.ico`；沒有圖檔時用內建的「紀」圖示 |
| 3/5 PyInstaller | 依 `installer\meeting_scribe.spec` 打包成 onedir：`dist\MeetingScribe\MeetingScribe.exe`＋`_internal\` |
| 4/5 自我檢查 | 執行打包版的 `MeetingScribe.exe selftest`，任何一項失敗就停止 |
| 5/5 Inno Setup | 依 `installer\meeting_scribe.iss` 產生 `dist\installer\MeetingScribe_Setup_{版本}.exe` |

參數：

| 參數 | 說明 |
|---|---|
| `-FfmpegPath 路徑` | 指定要附上的 ffmpeg.exe |
| `-SkipSelfTest` | 略過自我檢查 |
| `-SkipInstaller` | 只產生 `dist\MeetingScribe\`，不產生安裝檔 |

**版本號**取自 `pyproject.toml` 的 `version`，發佈新版前先修改。

### 相關檔案

| 檔案 | 說明 |
|---|---|
| `scripts\build.ps1` | 打包流程 |
| `installer\launch.py` | PyInstaller 進入點（與 `python -m meeting_scribe` 相同） |
| `installer\meeting_scribe.spec` | PyInstaller 設定：收錄 `assets\`、提示詞、OpenCC 字典、python-docx 範本；排除用不到的套件（numpy、QtWebEngine 等） |
| `installer\meeting_scribe.iss` | Inno Setup 設定：安裝畫面繁體中文、預設只裝給目前使用者 |
| `assets\icon.png` | 程式圖示（建議正方形、至少 256 × 256） |

### 為什麼用 onedir 而不是單一 exe

onedir 啟動較快（不必每次解壓縮到暫存資料夾），也比較不容易被防毒軟體誤判（SPEC 第 4 章）。
`dist\MeetingScribe\` 本身也能直接執行（免安裝），但 `_internal\` 必須與 `MeetingScribe.exe` 放在一起。

## 3. 安裝檔的行為

| 項目 | 說明 |
|---|---|
| 安裝位置 | 預設 `%LOCALAPPDATA%\Programs\MeetingScribe`（只裝給目前使用者，不需系統管理員權限）；安裝時可改選「安裝給所有使用者」 |
| 捷徑 | 開始功能表「MeetingScribe 會議紀錄」；可勾選桌面捷徑 |
| 系統需求 | Windows 10 以上、64 位元 |
| 解除安裝 | 移除程式檔案；**保留**設定（`%APPDATA%\MeetingScribe`）、金鑰（Windows 認證管理員）、會議資料與輸出檔 |
| 升級 | 直接執行新版安裝檔覆蓋即可（AppId 固定），設定與資料不受影響 |

### 靜默安裝（大量部署）

```powershell
.\MeetingScribe_Setup_0.5.0.exe /VERYSILENT /SUPPRESSMSGBOXES /CURRENTUSER /NORESTART /TASKS=desktopicon
```

- `/DIR="D:\Apps\MeetingScribe"`：指定安裝位置
- `/ALLUSERS`：安裝給所有使用者（需要系統管理員權限）
- 靜默解除安裝：`"%LOCALAPPDATA%\Programs\MeetingScribe\unins000.exe" /VERYSILENT`

## 4. 驗證

### 4.1 自我檢查（每次打包自動執行）

```powershell
.\dist\MeetingScribe\MeetingScribe.exe selftest --out .\build\selftest
```

不需要金鑰、不花費用，在本機完成一次處理：

| 檢查 | 確認的內容 |
|---|---|
| 資源檔、設定檔 | assets、提示詞、模型清單都有打包進去 |
| 金鑰保存 | Windows 認證管理員後端可用 |
| 繁簡轉換 | OpenCC 字典有打包進去 |
| ffmpeg 音訊轉檔 | 內附的 ffmpeg 可以轉檔、剪出語音範圍 |
| 匯入逐字稿 → 刪除贅字 → 產出文件 | 逐字稿 .docx、心智圖 PNG／XMind |
| 圖形介面 | 主視窗與播放元件可以建立 |

結果寫在 `selftest_report.txt`，全部通過時結束代碼為 0。

### 4.2 乾淨 Windows 驗證（SPEC 驗收標準）

用 **Windows 沙箱**（每次開啟都是全新、沒有 Python 的 Windows）：

1. 啟用沙箱（只需一次，需要系統管理員權限並重新開機）：控制台 →「開啟或關閉 Windows 功能」→ 勾選「**Windows 沙箱**」。
2. 執行：

   ```powershell
   .\scripts\test_clean_install.ps1
   ```

3. 沙箱會自動：靜默安裝 → 確認系統沒有 Python → 執行自我檢查 → 開啟主視窗（可目視確認）。
4. 結果寫在 `dist\clean_install_result.txt`。

也可以在一台沒有安裝 Python 的電腦上手動安裝，執行使用說明書第 8 章的自我檢查指令。

## 5. 發佈到 GitHub Releases

### 用 gh 指令

```powershell
gh release create v0.5.5 dist\installer\MeetingScribe_Setup_0.5.5.exe dist\installer\MeetingScribe_Setup_0.5.5.exe.sha256 --repo donny2582/meeting-scribe --target main --title "MeetingScribe 0.5.5" --notes-file 說明.md --prerelease
```

- **一定要連同 `.sha256` 檢查碼一起上傳**：程式的「版本」分頁下載後會比對檢查碼，沒有檢查碼的版本不提供安裝。
- 正式版（穩定版）拿掉 `--prerelease`；把預覽版改成穩定版：`gh release edit v0.5.5 --prerelease=false --latest`。
- 補傳或更新檔案：`gh release upload v0.5.0 檔案 --clobber`。

### 手動上傳

1. 打開 <https://github.com/donny2582/meeting-scribe/releases/new>。
2. 「Choose a tag」輸入 `v0.5.0` →「Create new tag」。
3. 填標題與說明，把 `dist\installer\MeetingScribe_Setup_0.5.0.exe` 拖到附件區（**只上傳安裝檔**，不要上傳 `dist\MeetingScribe\` 或 `build\`）。
4. 「Publish release」。

README 有兩個下載連結：Releases 頁面（列出所有版本），以及指定版本的直接下載連結。**發佈新版後請更新 README 的直接下載連結**。
（`releases/latest` 只會指到正式版，預覽版不會出現在那裡。）

## 6. 注意事項

- **數位簽章**：安裝檔沒有程式碼簽章，Windows SmartScreen 會顯示「Windows 已保護您的電腦」。正式在機關內部署時，建議向單位申請程式碼簽章憑證，
  在 `build.ps1` 產生安裝檔後以 `signtool` 簽署 `MeetingScribe.exe` 與安裝檔。
- **ffmpeg 授權**：內附的 ffmpeg（gyan.dev 的 full build）為 GPL 授權，公開散布時請在發佈說明註明來源：<https://www.gyan.dev/ffmpeg/builds/>。
- **不可放進 git 或安裝檔**：API 金鑰、錄音檔、逐字稿（`.gitignore` 已排除 `dist\`、`build\`、`assets\ffmpeg\*.exe`、錄音檔格式）。
- **防毒軟體誤判**：若單位的防毒軟體攔截，請將安裝檔與 `%LOCALAPPDATA%\Programs\MeetingScribe` 回報為誤判或加入例外。
